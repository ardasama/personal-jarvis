# MORPHY legacy contribution archive

This directory is a **local, non-executable archival snapshot** of engineering work produced for MORPHY. The original machine-specific documents are intentionally Git-ignored: they contain environment identifiers and must not be published automatically.

## Archived historical inputs (locally present; deliberately ignored)

- `DISCOVERY_REPORT.md`: historical Phase 0 discovery
- `ARCHITECTURE.md`: full Phase 1 architecture
- `PHASE_2_COMPLETION_REPORT.md` through `PHASE_6_COMPLETION_REPORT.md`: historical implementation reports
- `KERNEL_OBJECTS.md`: foundational object contracts
- `MEMORY_FABRIC_README.md`: memory subsystem lifecycle and contracts
- `COGNITIVE_INDEX.md`: MORPHY cognitive notebook index
- `MORPHY_MASTER_PROJECT_PLAN_AND_PHASE_PROMPTS.md`: 1,172-line historical ChatGPT Library master plan and phase-prompt pack

These files are preserved for **reference, diffing and provenance**, not for direct execution or implicit adoption.

## Boundaries

- MORPHY's original working repository remains separate and is not deleted or overwritten.
- Personal Jarvis's `AGENTS.md`, architecture, tests and code remain authoritative for **Personal Jarvis runtime behavior**.
- No historical MORPHY capability/test status is evidence of today's Jarvis capability.
- Never copy MORPHY's credentials, local memory items, environment variables or private notes into tracked files without explicit review.
- Import concepts and tests only where Jarvis has a measured gap; do not create a second agent runtime.
